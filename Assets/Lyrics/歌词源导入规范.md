# Alpha Island 歌词源导入规范

在“设置 → 外观 → 数据源 → 歌词源 → 自定义”中管理来源。默认来源是网易云、LRCLIB、酷狗。

## 来源与优先级

- 列表从上到下设置优先级，可上下移动或关闭单个来源。
- 为避免慢接口拖延显示，在线来源并发查询，优先等待第一项 1.2 秒；之后采用已经完成的有效结果，同批完成时仍按列表顺序选择。整轮最多 20 秒。
- 第一项为本地歌词且匹配成功时，直接使用本地结果，不请求网络。关闭全部在线来源即可仅使用本地库。
- 来源、顺序或本地库改变后会清除歌词缓存，并重新匹配当前歌曲。
- “重置”恢复三个默认来源的顺序和启用状态，不删除导入的文件。之后导入任一 LRC，即可重新启用本地库，重复文件不会重复保存。

## 导入外部来源 JSON

点击“导入来源 JSON”。文件为 UTF-8 / 带 BOM 的 Unicode 编码，最大 1 MB。不执行脚本或安装第三方程序集。

```json
{
  "schemaVersion": 1,
  "sources": [
    {
      "id": "http.my-lyrics",
      "name": "我的歌词库",
      "kind": "http",
      "enabled": true,
      "urlTemplate": "https://example.com/lyrics?title={title}&artist={artist}&album={album}&duration={duration}",
      "format": "json",
      "resultsPath": "",
      "lyricsPath": "syncedLyrics",
      "plainLyricsPath": "plainLyrics",
      "translationPath": "translatedLyrics",
      "titlePath": "trackName",
      "artistPath": "artistName",
      "albumPath": "albumName",
      "durationPath": "duration"
    }
  ]
}
```

- `id`：唯一标识，1–80 个字母、数字、点、下划线或短横线；省略时自动生成。使用 `http.` 前缀以免与默认项重名。同 ID 导入会更新原项。
- `name`：界面显示名称，最多 60 个字符。
- `kind`：外部接口为 `http`；内置项为 `builtin`（ID：`netease`、`lrclib`、`kugou`）；本地库为 `local`（固定 ID：`local`）。
- `urlTemplate`：GET 接口，使用 HTTPS；本机接口可使用 `http://localhost` 或回环地址。占位符仅放在路径或查询参数中，歌曲信息会自动进行 URL 编码。`duration` 单位为秒。
- `format`：`json` 或 `lrc`。
- `resultsPath`：结果对象或数组在响应中的位置，如 `data.items`。留空表示响应根节点。
- 其余 `*Path`：响应字段名，支持点分隔的嵌套对象。不需要的可选字段可设为空字符串；JSON 响应必须提供歌曲和歌手字段以及至少一种歌词。
- 最多 12 个来源；接口响应最多 1 MB，数组最多检查前 100 项。无效、超时或不匹配的结果自动跳过。

JSON 响应可以是一个对象，也可以是对象数组，例如：

```json
{
  "trackName": "示例歌曲",
  "artistName": "示例歌手",
  "albumName": "示例专辑",
  "duration": 180,
  "syncedLyrics": "[00:01.00]第一句\n[00:04.00]第二句",
  "translatedLyrics": "[00:01.00]译文一\n[00:04.00]译文二"
}
```

没有时间轴时可返回 `plainLyrics`，会根据曲目时长分配显示时间。原文与翻译均为 LRC 时按时间戳合并。歌名、歌手、专辑和时长用于过滤同名歌曲与不同版本。

`lrc` 接口应直接返回 LRC 文本，并包含 `[ti:歌名]`、`[ar:歌手]` 标签，供匹配当前歌曲。`[al:专辑]`、`[length:03:00]` 可选。

## 导入本地歌词

点击“导入本地歌词”，可一次选择最多 100 个 `.lrc` 文件。每份最多 1 MB，本地库最多 1000 首、64 MB。导入时复制文件，原文件移动后仍可使用；相同内容自动去重。

推荐 UTF-8 编码，并使用以下标签：

```lrc
[ti:示例歌曲]
[ar:示例歌手]
[al:示例专辑]
[length:03:00]
[00:01.00]第一句歌词
[00:04.00]第二句歌词
```

无标签时支持 `歌手 - 歌名.lrc` 文件名；只有歌名时，仅在播放器未提供歌手且没有同名歧义时匹配。建议总是补齐歌名和歌手，减少错配。至少包含一行有效时间戳。

本地副本位于 `%LOCALAPPDATA%\alpha-island\config\lyrics\local`；说明和示例位于同级“导入说明”目录。配置文件保存于当前 Windows 用户的数据目录，安装包不包含个人导入内容。

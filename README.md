# Alpha Island

[简体中文](README.md) · [English](README.en.md)

**让媒体、通知和常用工具，集中在 Windows 桌面顶部。**

Alpha Island 是一个使用 C# 与 WPF 开发的桌面状态面板。平时收起为细条，播放音乐、收到通知或执行任务时展开为胶囊；需要更多操作时，再打开完整卡片。液态玻璃外观、侧边组件切换和多岛布局，让常用信息保持触手可及。

![Alpha Island 音乐卡片](docs/screens/music-lyrics.png)

## 功能

| 模块 | 可以做什么 |
| --- | --- |
| 媒体与歌词 | 读取 Windows 媒体会话，控制播放、显示封面与实时频谱；同步歌词、翻译及逐字高亮，支持歌词源排序、自定义源和本地 LRC。前奏与可识别的间奏以四个圆点过渡。 |
| 通知中心 | 汇总系统与应用消息，按应用筛选、堆叠、查看和清除；支持自定义提示音。 |
| 设备与系统状态 | 展示 CPU、内存、网速、电源状态和受支持设备的电量；提供蓝牙连接及充放电提示。 |
| 屏幕工具 | 截图 OCR、颜色吸管、文字翻译、扫码；分别提供语音识别与区域翻译字幕。 |
| AI 与外部助手 | 配置兼容接口的对话模型、人格提示词与语音识别服务；通过本地桥接展示外部助手状态和工具审批。 |
| 时间与效率 | 番茄钟、自然语言提醒、生产力统计、本地习惯建议与系统健康预警。 |
| 桌面工具 | 剪贴板历史、文件中转、快速启动与下载状态提示。 |
| 外观与扩展 | 主题与动效设置、欢迎动画和音效组合、游戏模式，以及可独立启停的插件。 |

语音和翻译功能取决于已配置的识别或翻译服务。设备电量与控制能力取决于 Windows、硬件协议和对应插件；不会为未上报的数据编造读数。

当前版本：**0.2.32**。

主安装包不附带可选插件。插件源码与构建脚本已移至同级独立目录 `alpha-island-plugins/`，发布包位于其中的 `packages/<版本>/`。解压到设置中打开的插件目录后再启用；现有插件和配置在主程序升级时保留。外部翻译的应用名与快捷键默认留空，按需自行配置。

Codex 状态接入可在设置中检查实际通道、启用与信任情况。支持的版本可补充读取本地任务状态；配置、适用范围与排查步骤见 [Codex 跨电脑状态识别](docs/Codex跨电脑状态识别.md)。

## 界面与操作

- 鼠标靠近主岛查看内容，点击岛外收起；支持在对应内容上右键置顶。
- 点击右侧切换条进入下一个组件，在线条上滚轮切换；长按展开组件菜单，松手选择。
- 卡片内的滚轮用于滚动内容，方便查看较长的通知、对话或设备列表。
- 多项活动可保留为侧岛，点击切换到对应内容。
- 浏览器在主屏最大化或全屏时自动收为细条，点击可临时展开；可在交互设置中关闭。
- 托盘图标打开设置；可配置快捷键、游戏模式和启动欢迎组合，默认以项目 Logo 动画欢迎。
- 设置 → 常规 → 界面语言，可选择跟随系统、简体中文或 English；重启后统一应用于界面和内置插件。语言资源完全本地，不消耗 API token。
- **多显示器**：主岛驻留于当前系统主显示器，响应主屏、分辨率、缩放和工作区变化。适配范围与验证边界见 [多显示器兼容](docs/多显示器兼容.md)。

## 运行与开发

- Windows 10 2004（19041）及以上，或 Windows 11。
- 从源码运行需要 **.NET 8 SDK**；Visual Studio 需安装“.NET 桌面开发”工作负载。
- 面向已有程序文件运行时，需要对应的 .NET 8 Desktop Runtime；自包含发布包可附带运行库。

```powershell
git clone https://github.com/l-egend/alpha-island.git
cd alpha-island
dotnet restore alpha-island.sln
dotnet build alpha-island.sln -c Debug
dotnet run --project alpha-island.csproj -c Debug --no-build
```

也可以用 Visual Studio 打开 `alpha-island.sln`，将 `alpha-island` 设为启动项目后按 F5。

日常开发使用 Debug 构建与必要回归；完成可用更新后同步生成安装包，默认只保留最近两个版本，并清理旧打包展开目录。构建及发布流程见 [开发与构建](docs/开发与构建.md) 和 [脚本说明](tools/README.md)。

## 配置与数据

设置、插件配置及本地记录集中保存在：

```text
%LOCALAPPDATA%\alpha-island\config
```

设置 → 关于可打开配置目录。API 密钥使用当前 Windows 用户的 DPAPI 加密保存；在线模型、翻译与歌词源需要访问对应服务。配置、密钥及个人记录不应提交到仓库，详见 [AI 验证与配置目录](docs/AI验证与配置目录.md)。

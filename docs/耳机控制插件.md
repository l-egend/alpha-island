# 耳机控制 / Earbud controls

通过设备私有蓝牙通道读取受支持耳机的分路电量，并按实际能力提供降噪、EQ 等控制。先在 Windows 中配对和连接音频，再按插件说明连接控制通道。

安装包、版本、要求和使用方式以 [中文说明](../examples/OppoPodsPlugin/README.md) 和 [插件目录](../README.md) 为准。

Read individual battery channels and control supported earbud features such as noise cancellation and EQ. Pair and connect audio in Windows first, then follow the plugin guide for its control connection.

See the [English instructions](../examples/OppoPodsPlugin/README.en.md) and [plugin catalog](../README.en.md) for packages, versions, requirements and usage.

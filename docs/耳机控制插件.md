# 耳机控制插件

接入日期：2026-10-04。插件 ID 为 `oppo.pods`，版本 `0.1.2`，使用岛的插件 API 1。
当前开发版本已安装并启用，卡片名称为“耳机”，设置中的名称为“耳机控制 · OPPO / 一加 / realme”。

## 使用

1. 在 Windows 蓝牙设置中配对耳机，退出原 OppoPodsManager，避免争用私有连接。
2. 在岛的设置 → 插件中启用“耳机控制”。当前安装已开启。
3. 切换到“耳机”卡片，点击“刷新”，选择耳机，再点击“连接”。
4. 等待读取完成后，按卡片显示的可用功能调整设置。

自动连接默认关闭。插件设置可开启自动连接、断线重连，并填写首选耳机名称。
发现多个候选耳机时，自动连接需要唯一匹配的首选设备；手动连接可以明确选择目标。
型号覆盖默认“自动识别”，识别失败时可按实际型号选择，不应选择其他型号来强行开放设置。

## 已接入的功能

| 功能 | 当前卡片 |
| --- | --- |
| 状态 | 左耳、右耳、充电盒电量与充电状态，佩戴状态、固件版本、编解码器 |
| 降噪 | 按型号提供关闭、通透、降噪及可用档位 |
| EQ | 读取和切换设备提供的预设 |
| 空间音频 | 按协议能力提供模式选择或开关 |
| 游戏 | 游戏模式、游戏音效开关 |
| 双设备 | 双设备开关、其他设备连接/断开、优先设备选择 |

型号资料包含 OPPO 56 条、realme 49 条、一加 32 条，共 137 条。
功能同时受型号资料和设备实际响应限制，不代表全部型号都具备表内功能。
自定义 EQ 编辑、固件升级和手势配置不在当前卡片范围内。

连接和周期读取不会主动修改音效。设置由用户操作触发，发送后等待设备回读；收到确认前保留上次已确认的状态。
电量每约 2 秒查询。各分路超过 10 秒未更新时显示“—”；完整响应缺少的分路或明确不可用的电量立即清空。单分路通知不清除其他仍有效的分路。整个连接超过 15 秒没有协议响应时清空电量并转为离线。
右键可独立顶置耳机卡片；禁用或删除插件也会撤下它的顶置小岛。

左右耳和盒电量用按百分比填充的电池条及数字显示：≤20% 为红色，21–50% 为橙色，>50% 为绿色。电量改变时平滑过渡，设备明确报告充电时播放闪电呼吸动画；未知、过期和断联立即清空。隐藏页面、减弱动效、节能及软件渲染会停止动画。显示控件由新版宿主 SDK 提供，参见 [设备电量显示](设备电量显示.md)。

卡片内容支持内部滚动，操作下拉框、滑块或滚动内容时保留对应控件的滚轮行为。

## 禁用、删除与安装包

禁用：在设置 → 插件中关闭“耳机控制”，卡片撤下，后台读取与私有蓝牙连接停止。设置保留，重新开启即可恢复。

当前开发安装目录：

```text
X:\FixtureWorkspace\alpha-island\bin\Debug\net8.0-windows10.0.19041.0\plugins\oppo.pods
```

卸载：在设置 → 插件点击“耳机控制”的“卸载”，自动停止读取与连接、撤下卡片及顶置，删除实际插件目录和宿主设置。删除失败时显示原因及“重试卸载”。
再次构建插件项目会自动部署到对应 Debug/Release 输出目录；临时停用直接使用开关即可。

独立安装包：

```text
X:\FixtureWorkspace\alpha-island\bin\packages\OppoPodsPlugin-0.1.2.zip
```

手动安装时，把包内插件文件解压到 `%LOCALAPPDATA%\alpha-island\plugins\oppo.pods`，然后刷新插件列表。
设置中的“打开插件目录”指向这个用户目录。当前开发版使用主程序旁的目录，不要再向用户目录安装一份相同 ID 的插件。
替换已经加载的 DLL 前先退出岛，再复制新文件并重启。


# 本机 Agent / Local Agents

向本机已配置的助手发送任务、查看回答和审批。发现可执行程序不等于已登录，使用前应确认该工具能独立正常对话。

安装包、版本、要求和使用方式以 [中文说明](../examples/LocalAgentsPlugin/README.md) 和 [插件目录](../README.md) 为准。

Send tasks to configured local assistants and view responses and approvals. Executable discovery does not verify login; confirm the tool can hold a conversation independently first.

See the [English instructions](../examples/LocalAgentsPlugin/README.en.md) and [plugin catalog](../README.en.md) for packages, versions, requirements and usage.

# 设备电池与 2.4G 插件（0.1.122）

展开岛，在组件菜单中选择“电池”，即可查看当前发现的蓝牙、受支持的 2.4G 外设和手柄。列表支持滚动、手动刷新，显示设备名、连接类型、充电状态和电量来源。

蓝牙使用现有系统服务，并补齐程序启动前已经连接的设备快照；启动时读取已有设备不会额外弹出连接提醒。兼容的耳机插件可以贡献左右耳、耳机盒等独立读数。

2.4G 读取由单独安装并手动启用的“2.4G 设备电量”插件提供，支持型号、已知限制和来源见独立插件包中的 README.md 与 SOURCES.md。不依赖本机 Python。未上报电量显示“未上报”，手柄档位与电压估算均作明确标示。

设备按物理标识区分，多接口不会按同一型号误合并。插件完整快照中消失的设备会被撤销；插件关闭或崩溃后其贡献退出列表。读取在插件进程完成，主程序只保存内存快照，不进行原始 HID 探测。

插件 SDK API 4 新增完整设备电池快照接口，API 1～3 插件继续兼容。统一电池卡片属于主程序，因此关闭 2.4G 插件后仍可查看蓝牙电池。

## 本机设备核验（2026-10-18）

| 设备 | 当前结果 |
| --- | --- |
| G502 LIGHTSPEED | 接收器实测成功，电池电压 4.149 V，对应约 97%；界面明确标注为估算 |
| MCHOSE K5 Ultra | 官方 M HUB 只读协议实测成功，设备上报 61%；支持接收器及有线接口，不需要一直打开网页驱动 |
| 飞智黑武士 4 Pro | 现已枚举到实体手柄，Xbox 模式走系统报告；首次枚举时 XInput 返回“外接供电”，随后 Windows 电池容量报告上报 100%。单手柄时合并 HID 与 XInput 身份，经典 DInput 专用接口仍未实机验证 |

设备协议和驱动可能只返回档位、外接供电或未知状态。电池卡片会保留这种区别；接收器在线也会单独说明，便于区分“接收器已插入”和“外设正在上报电量”。

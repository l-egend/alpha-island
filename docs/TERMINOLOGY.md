# 界面术语 / Interface terminology

| 中文名称 | English name | 定义 / Definition |
| --- | --- | --- |
| 主面板 | Main panel | 位于主显示器顶部的主要悬浮界面。 / The primary floating interface at the top of the primary display. |
| 辅助面板 | Auxiliary panel | 主面板旁用于展示其他活动的独立界面单元。 / A separate interface element beside the main panel for another activity. |
| 状态条模式 | Status bar mode | 主面板的最小化显示模式，减少占用的屏幕空间。 / The main panel's minimized display mode with a smaller screen footprint. |
| 摘要视图 | Summary view | 显示当前活动、简要状态或通知摘要的紧凑视图。 / A compact view of an activity, status or notification summary. |
| 卡片视图 | Card view | 显示详细内容与交互控件的展开视图。 / An expanded view with detailed content and controls. |
| 组件切换控件 | Component switcher | 主面板右侧用于切换组件、打开组件菜单的控件。 / The control on the right of the main panel for switching components and opening their menu. |
| 多面板布局 | Multi-panel layout | 主面板与辅助面板同时显示的布局。 / A layout displaying the main panel and auxiliary panels together. |

项目介绍与使用文档统一采用表中的界面术语。Alpha Island 为项目名称；这些术语不改变功能、配置字段或已有接口。

Documentation uses these interface names consistently. Alpha Island remains the project name; these terms do not change functionality, configuration keys or existing APIs.

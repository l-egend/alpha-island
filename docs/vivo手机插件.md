# vivo 手机连接 / vivo phone connection

只读办公套件已有的连接记录。当前在线状态需由套件运行与对应设备信息共同确认，历史记录不会单独作为在线依据。

安装包、版本、要求和使用方式以 [中文说明](../examples/VivoOfficePlugin/README.md) 和 [插件目录](../README.md) 为准。

Read existing connection records from the desktop suite. Online state requires both a running suite and matching current device information; history alone is not treated as a live connection.

See the [English instructions](../examples/VivoOfficePlugin/README.en.md) and [plugin catalog](../README.en.md) for packages, versions, requirements and usage.

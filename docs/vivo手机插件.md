# vivo 手机插件

更新日期：2026-10-04，插件版本 0.1.1，插件 ID 为 vivo.office。

原“应用联动”卡片、系统卡上的手机附加行、系统设置中的旧 vivo 开关，以及宿主内置监控已移除。
现在在“设置 → 插件”管理“vivo 手机”，通过组件菜单打开它的卡片。

卡片显示以下四个字段：

| 字段 | 行为 |
| --- | --- |
| 设备名称 | 当前连接有可靠记录时显示“设备名称”；断开或办公套件退出后显示“最近设备” |
| 连接方式 | 显示 USB、Wi-Fi、Wi-Fi 直连、明确的远程连接，其他类型保留套件记录值 |
| 连接时间 | 最近一次成功连接的本机日期与时间，格式为 yyyy-MM-dd HH:mm:ss；不是连接持续时长 |
| 内网 IP | 优先读取当前设备地址；仅有历史地址时标为“最近内网 IP”，缺失时显示“—” |

每两秒只读连接记录；不会读取笔记、日历、传输数据库，不提取账号；IP 仅使用办公套件已有的设备内网地址记录。
当前连接必须由办公套件仍运行及当前设备列表确认，不能只靠历史 connectState 或较新的时间戳断言在线。
字段缺失时显示“—”。记录正在重写时保留上一次字段，改用“最近设备”标记；删除记录文件后清空显示。
如果 phone 数组尚未写入，可以由当前设备 ID 列表确认同一个设备；不同设备的字段不会拼在一起。

右键可独立顶置，主岛摘要同步设备名称、方式和连接时间；不影响其他卡片顶置。
新的成功连接时间或可靠的断开到连接变化会弹出 6 秒“手机连接成功”提醒，仅显示设备名称、连接方式和连接时间。启动与启用插件不会补弹历史记录；轮询、稍后的在线确认和记录写入中的短暂未知不会重复弹出。查看其他卡片时提醒显示在旁侧。
停用插件立即撤下卡片与顶置、停止刷新。“卸载”一键停止插件并删除其实际目录及设置，适用于 exe 旁的插件和用户插件目录；删除失败时显示原因及“重试卸载”。“打开此插件目录”仍可查看插件文件。

![插件卡片预览](screens/vivo-plugin.png)

源码位于同级独立目录 `alpha-island-plugins/examples/VivoOfficePlugin/`，发布包位于该目录的 `packages/<宿主版本>/`。
在独立插件目录执行 `tools/build-plugins.ps1` 可生成插件与对应源码包，不包含 vivo 软件或用户连接记录。

vivo 插件字段解析、真实设置开关、连接事件去重与小岛提醒、独立顶置、停用及一键卸载共 87 项专项检查通过。
真实手机连断以办公套件写入的记录为准，更新速度由办公套件的写入时机和两秒刷新周期共同决定。

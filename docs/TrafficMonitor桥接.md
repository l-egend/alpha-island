# TrafficMonitor 网络数据 / TrafficMonitor network data

需要两部分：Alpha Island 数据源插件，以及安装到 TrafficMonitor x64 中的原生桥接。两程序应使用同一 Windows 用户。桥接未连接时宿主会使用本机采样。

安装包、版本、要求和使用方式以 [中文说明](../examples/TrafficMonitorPlugin/README.md) 和 [插件目录](../README.md) 为准。

Requires two components: the Alpha Island data-source plugin and a native bridge installed in TrafficMonitor x64. Run both programs as the same Windows user. The host uses local sampling when the bridge is unavailable.

See the [English instructions](../examples/TrafficMonitorPlugin/README.en.md) and [plugin catalog](../README.en.md) for packages, versions, requirements and usage.

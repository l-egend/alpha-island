# API 对话

在 Alpha Island 中与兼容接口的模型对话，支持流式回答、TXT 人格、语音指令和可选工具调用。

- 版本：**0.1.41**
- 插件 ID：`ai.api-chat`
- 宿主插件 API 要求：**7**

## 使用条件

准备可用的服务地址、模型名称和 API Key；语音输入还需配置语音识别服务。

## 主要功能

- 提供服务商预设、模型获取或手动填写，以及连接测试。
- 管理对话历史，导入 TXT 人格；修改人格后应新建会话。
- 按开关使用桌面工具、自然语言提醒和按需状态读取。

## 安装与使用

先按[通用安装步骤](../../README.md#install)放置完整插件目录，再进行以下操作：

1. 安装后打开“设置 → 插件 → API 对话 → 插件设置”。
2. 填写接口地址、模型和密钥，保存密钥并测试连接；切换地址后重新测试。
3. 启用插件，打开 AI 对话卡片并发送消息。需要时单独开启工具调用和按需状态读取。

## 说明与限制

- 不会默认把所有系统状态附加到每次对话；相关开关和模型的工具调用能力共同决定能否查询。
- 发送给模型的对话及获准工具结果会交给所配置的服务，并计入其用量；密钥按当前 Windows 用户加密保存。
- 人格仅在会话首次成功请求时附加，普通无状态 API 不保证后续完整保留人格。

## 从源码构建

在插件源码根目录执行：

```powershell
dotnet build examples/ApiChatPlugin/ApiChatPlugin.csproj -c Release
```

需要 Windows 和 .NET 8 SDK。普通构建只生成文件；安装时仍需手动放置完整插件目录。本机批量打包命令在仓库之外单独维护。

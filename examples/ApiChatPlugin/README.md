# API 对话插件

负责模型连接、岛内对话和历史管理。禁用会停止请求并隐藏入口，卸载保留密钥与历史。设置位于 config，密钥在 config/ai/secrets.dat，历史在 ai/sessions。

API 对话不自动读取或附加系统状态，也不重发旧会话状态包。每次请求发送内置系统规则、正常对话历史及可用工具说明；人格只在会话首次被接口接受的请求中附加，工具续接不重复。支持工具调用的模型需要岛内信息时，通过只读 get_island_info(section) 查询对应分区；数据只在本次工具调用过程中返回，后续追问重新读取。工具说明及工具结果均会计入 API 输入用量，可在“状态/用量”查看最近一次读取与接口用量。

状态分区包括设备电量、电源、媒体、音量、系统资源、网络/今日流量、天气、番茄钟、今日统计、通知数量、助手任务、剪贴板历史数量、本地提醒数量、启动器、插件、岛状态、隐私占用和前台应用。电量沿用电池卡片的来源合并、断连与过期处理，未知值不编造。状态接口不返回通知/剪贴板正文、设备标识、应用路径或密钥。

“人格提示词”支持手动编辑和导入 TXT。人格文件夹为 config/ai/personas，含编写规范与简洁助理示例；支持 UTF-8、带 BOM 的 Unicode 及常见 GBK 文本，文件最多 64 KB、正文最多 8000 字符。原文件不被修改，用户修改的规范不被覆盖；只更新完全匹配旧版内置内容的规范。人格仅在会话首次成功请求中发送；重开历史或重启不会重复，修改后需新建或清空会话。普通无状态 API 后续只参考历史，无法保证完整保留人格。旧版自定义系统提示词作为人格偏好保留；内置系统规则固定。

“允许按需读取岛内状态”控制状态访问，“允许助手调用工具”控制工具调用。具体提醒事项仍通过原有 list_reminders 查询。
设置提供常用服务商预设，选择后填入接口地址，也可保留自定义地址。模型既可从接口获取，也可手动输入后测试；切换地址会使旧验证失效，已保存密钥不会直接用于另一个接口。窄窗口采用上下布局，插件画面按显示器缩放输出。

# vivo 手机连接

读取 vivo 办公套件已有的连接记录，显示设备名称、连接方式、时间和内网地址，并提醒新的连接。

- 版本：**0.1.3**
- 插件 ID：`vivo.office`
- 宿主插件 API 要求：**2**

## 使用条件

本机已安装 vivo 办公套件并产生过连接记录；当前在线判断需要套件运行且提供对应设备信息。

## 主要功能

- 显示当前设备，或断开后的最近设备记录。
- 区分当前内网地址和历史地址，不混用其他设备或电脑自身的地址。
- 识别新连接，启动和首次打开卡片时不补弹旧记录。

## 安装与使用

先按[通用安装步骤](../../README.md#install)放置完整插件目录，再进行以下操作：

1. 先用 vivo 办公套件完成一次手机连接。
2. 安装并启用插件，打开 vivo 手机卡片查看连接信息。
3. 套件关闭或手机断开后，按卡片中的“最近设备”标识查看历史记录。

## 说明与限制

- 只读必要的连接字段，不读取笔记、日历、账号、传输数据库或手机电量。
- 这是连接状态卡片，不提供手机控制、文件传输或通知镜像。
- 缺少记录或字段时显示未知，不推算实时在线状态。

## 从源码构建

在插件源码根目录执行：

```powershell
dotnet build examples/VivoOfficePlugin/VivoOfficePlugin.csproj -c Release
```

需要 Windows 和 .NET 8 SDK。普通构建只生成文件；安装时仍需手动放置完整插件目录。本机批量打包命令在仓库之外单独维护。

# vivo 手机插件

只显示三个字段：设备名称、连接方式、最近一次成功连接时间。

插件只读 vivo 办公套件写入的 historyPhone.json 和 config.json，不读取笔记、日历、账号、电量或传输数据库，不调用私有控制接口。
每两秒刷新一次。办公套件运行且当前设备列表包含该设备时显示“设备名称”；断开或套件退出后显示“最近设备”，保留最后的名称、方式和连接时间。
暂时写入不完整时显示上一次记录，并撤掉当前连接标记；缺失字段显示“—”，不推算电量、连接时间或实时状态。

检测到新的成功连接时间或设备从断开变为当前连接时，在岛上提醒“手机连接成功”，持续 6 秒。连接列表暂时不可用时，仍可依据最近两分钟内更新的成功连接时间提醒，不把历史记录断言为当前在线。启动、启用插件及打开卡片只读取基线，不补弹旧记录；连续轮询和同一次连接的稍后在线确认不会重复提醒。配置写入中的短暂未知也不会制造重连提醒。
提醒只显示设备名称、连接方式和连接时间。查看其他卡片时提示放在旁侧；禁用或卸载插件同时撤下提醒。

在岛的“设置 → 插件”中开关“vivo 手机”。停用会移除卡片和顶置、停止刷新。
卸载方式：在“设置 → 插件”的“vivo 手机”下点击“卸载”，自动停止刷新、撤下卡片与顶置、删除插件目录和设置。文件占用或权限不足时显示原因，可点击“重试卸载”。不要在插件仍运行时替换 DLL；更新后重启岛。

需要 vivo 办公套件写入过连接记录。套件关闭后仍能查看最近记录，当前连接判断要求套件保持运行。

构建：dotnet build examples/VivoOfficePlugin/VivoOfficePlugin.csproj -c Debug
构建后部署到岛的 bin/Debug/net8.0-windows10.0.19041.0/plugins/vivo.office。
可分发的文件为插件 DLL、deps.json、plugin.json、README.md；宿主提供 PluginSdk。

# 2.4G 设备电量插件

设备读数汇入 Alpha Island 的“电池”卡片，与 Windows 蓝牙电量、耳机插件的独立电池读数一起显示。安装后需在设置 → 插件中手动启用。无需 Python、额外常驻程序或厂商管理软件。

支持路径：

- MCHOSE K5 Ultra：`3837:1018` 接收器及 `3837:4038` 有线接口，读取官方 M HUB 的 `0x0900` 设备信息指令。实测收到 61%（设备上报值），不依赖网页保持打开。
- ATK / VXE `373B:1216`、DARKRIM SHADOW `3654:6901`：按照参考项目公开的查询协议读取。
- 罗技 LIGHTSPEED / Unifying HID++ 2.0：首次协商协议，使用指定的长报文接口，读取设备实际支持的 `0x1004`、`0x1000` 或 `0x1001` 电池特性。只有电压时，显示带“约”字的估算值，悬停可查看电压和来源；不会当作设备上报的精确百分比。
- 标准 HID Battery Strength 字段：按描述符定义解析，不猜测报文字节。
- 飞智黑武士 4 Pro：经典 DInput 厂商接口（`04B4:2412`、`FFA0`）可查询型号及厂商电量档位；不将档位伪装成百分比。XInput / 接收器模式优先使用 Windows 电池报告，不切换设备模式、不接管按键。该专用接口已做报文校验，尚未完成本机手柄实测。
- 其他手柄：Windows RawGameController 电池报告；仅提供档位的 XInput 设备显示“极低 / 低 / 中 / 充足”。驱动返回外接供电或没有电量时如实显示。

已插入接收器不代表外设已开机。接收器在线但外设休眠、未连接或未上报时，会明确说明原因。未提供公开协议或电池字段的设备无法保证读取百分比。K5 Ultra 查询包含命令、型号、长度与 XOR 校验，接收器空响应或无效百分比不会生成假读数。

默认每 2 秒查询状态，支持 1～10 秒间隔；设备资料缓存 30 秒，接收器和手柄插拔在约 150ms 后触发合并刷新，也可以点击卡片中的“刷新”重新检测。不同物理设备最多并行查询两个，同一设备仍按顺序通信。完整快照会撤销已移除设备；停用插件后清除其贡献的设备，蓝牙列表不受影响。超过 3 分钟未更新的百分比会失效。

读取运行在独立插件进程，HID 查询仅针对白名单设备的厂商接口，使用独立异步读写句柄、查询超时和取消；不会写入 DPI、配对、灯效或固件配置。

来源见 [SOURCES.md](SOURCES.md)。本目录为独立的 C# 实现，不分发上游 Python 源文件。

Xbox 模式下的手柄继续使用系统电池报告。只有一个实体 Xbox 兼容 HID 和一个 XInput 插槽时，合并其身份，避免同一手柄在首次发现时重复显示；多手柄时不猜测对应关系。系统返回“外接供电”时，会明确说明驱动未返回电池百分比。

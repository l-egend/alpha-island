# 耳机控制插件

支持 OPPO／一加／realme、vivo／iQOO、华为的私有蓝牙控制；小米／Redmi、漫步者和 AirPods 按后端现有能力提供状态读取。设置按设备实际能力显示。
首次在岛设置 → 插件中启用，再选择“耳机”卡片，刷新、选择已配对耳机并连接。
配对在 Windows 蓝牙设置中完成。原耳机管理程序请先退出，避免争用私有连接。

卡片提供分路电量、降噪、EQ、游戏模式、空间音频和双设备开关。
EQ 当前支持设备预设的读取与切换；自定义 EQ 编辑、固件升级和手势配置暂未接入。
设置页可开启自动连接、断线重连，指定首选耳机和型号覆盖。
连接和读取不会自动改写耳机音效；设置仅在卡片操作时下发。

禁用：设置 → 插件关闭本插件，卡片和后台服务一并停止。
卸载：在设置 → 插件点击本插件的“卸载”，自动停止连接与服务、撤下卡片和顶置，删除插件目录及设置。文件占用或权限不足时显示原因和“重试卸载”。
普通 VS 构建自动复制插件到主程序 Debug/Release 输出目录。删除已安装插件后，后续再次构建插件工程会重新部署。

插件不依赖原 OppoPodsManager EXE。源码及第三方许可见 source/（发布包）和 THIRD-PARTY-NOTICES.md。
此版本含 137 条型号资料；功能随型号、固件和设备返回的能力变化。
0.1.1：各分路电量独立更新与过期；完整查询不包含的分路立即清空，通知中的其他分路保留到有效期结束。
电量每约 2 秒查询；超过 10 秒未更新显示“—”，连接超过 15 秒无响应进入离线并按重连设置处理。
0.1.2：左右耳与盒使用按百分比填充的电池条，并保留数字电量；低电量红色、中段橙色。数值更新平滑过渡，设备报告充电时显示闪电呼吸动画。未知、过期或断联立即清空；隐藏、减弱动效及节能模式停止动画。需要含 DeviceBatteryIndicator 的新版岛及 SDK。

0.1.3：同步用户提供的 OppoPodsManager 2.0 程序，增加 43 个 vivo／iQOO 显示型号、华为能力路由、Apple／Beats 广播型号识别，以及小米／Redmi、漫步者基础后端。原 OPPO／一加／realme 的 137 条型号数据保留。
新增品牌需先在 Windows 中连接音频，再点击刷新；AirPods 通过可解码的明文 BLE 广播读取状态，可再次刷新选择广播设备，加密广播和 Windows 控制通道尚不支持。
控制范围限于现有岛卡片的降噪、内置 EQ、游戏模式、空间音效和双设备开关；新品牌的高级多设备操作、固件升级等未暴露为可用按钮。新增型号需要真实设备测试，不以型号存在代替硬件验证。
